# Inventory Audit and Reconciliation Tool

An interactive inventory audit and reconciliation application for identifying stock discrepancies, updating inventory counts, tracking audit status, and reviewing audit results.

## Project Overview

The Inventory Audit and Reconciliation Tool helps warehouse teams compare expected inventory quantities against actual counts. It highlights discrepancies so users can identify inventory issues and track items that require further review.

This project demonstrates practical applications of inventory management, warehouse operations, and front-end web development.

## Features

- **Inventory Tracking:** View inventory records, including item IDs, descriptions, warehouse locations, and expected quantities.
- **Stock Count Updates:** Enter actual inventory counts and refresh calculations.
- **Discrepancy Calculations:** Automatically calculate differences between expected and actual quantities.
- **Audit Status Tracking:** Identify items that require review and track audit progress.
- **Audit History:** Maintain audit-related information within the application.
- **Local Storage:** Save inventory data and audit history in the browser so information persists between page refreshes.
- **Interactive Interface:** Review inventory records and audit results through a user-friendly web interface.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Use

1. Open the application in your web browser.
2. Review the inventory records and expected stock quantities.
3. Enter actual inventory counts for the items being audited.
4. Refresh the discrepancy calculations.
5. Review items flagged for discrepancies.
6. Update audit statuses as items are reviewed or resolved.
7. Refresh the page to verify that saved inventory and audit information persists.

## Project Purpose

This project demonstrates how a browser-based application can support warehouse inventory accuracy, discrepancy investigation, and audit tracking. It combines operational problem-solving with interactive web development.

## Future Improvements

Potential enhancements include exporting audit reports, adding search and filtering options, and expanding inventory reporting capabilities.
